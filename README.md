# 🍴 Food Fiesta

Food Fiesta is a multi-page food website that I built as one of my first frontend development projects.

The project was created to practice building a complete website structure using HTML and CSS, while learning how multiple pages work together to create a consistent user experience.

## ✨ Pages

- 🏠 Home
- 🍽️ Menu
- 📅 Booking
- 📞 Contact
- 📊 Dashboard

## 🛠️ Technologies

- HTML5
- CSS3

## 🎯 What I Learned

While building Food Fiesta, I practiced:

- Creating multi-page websites
- Structuring HTML documents
- Designing layouts with CSS
- Creating navigation between pages
- Organizing frontend project files
- Thinking about user experience and page structure
